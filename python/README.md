# verifiably-atoms

A recoverable filesystem effect engine: a change to many files on disk ends finished,
undone or halted, never silently half-done, and after a crash the engine tells its own
changes from another writer's by reading the disk. Part of
[verifiably](https://github.com/verifiably/docs/blob/main/overview.md).

Usage, platform support and the design live in the repository:
<https://github.com/verifiably/atoms>.
